# Image structure

```text
assets/images/
├── hero/
│   └── writing-culture.webp
└── projects/
    └── <category>/<project-slug>/
        ├── cover-1200x900.webp
        ├── gallery-01-1440x1080.webp
        ├── gallery-02-1100x825.webp
        └── gallery-03-1100x825.webp
```

Recommended format: WebP, sRGB, 1600–2000 px on the longest edge and generally under 400 KB per image.
