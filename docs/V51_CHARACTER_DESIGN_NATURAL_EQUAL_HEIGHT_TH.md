# V51 — Character Design natural equal height

แก้ไขตามคอมเมนต์ล่าสุดโดยเปลี่ยนวิธีจัดวางใหม่ทั้งหมด

- ยกเลิกการบังคับความสูงตายตัวของภาพ Character Design
- ยกเลิกการใช้ `height: 100%` และ `object-fit: cover` ที่ทำให้ภาพซ้ายแสดงผลผิดเพี้ยน
- คำนวณสัดส่วนคอลัมน์จากขนาดไฟล์จริง 1400×1100 และ 1200×1500
- ภาพซ้ายและขวาจึงมีความสูงเท่ากันตามธรรมชาติ โดยไม่ยืดและไม่ครอป
- ยังคงมีช่องว่างระหว่างภาพชัดเจน
- Mobile กลับไปแสดงผลคอลัมน์เดียวตามสัดส่วนจริง
- อัปเดต cache version เป็น v51
