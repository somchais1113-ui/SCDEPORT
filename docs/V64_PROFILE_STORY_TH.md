# V64 Profile Story

## เป้าหมาย
ปรับ Profile จากข้อความแนะนำตัวแบบสั้น ให้เป็นหน้าเล่าเส้นทางอาชีพที่สอดคล้องกับ Resume และรองรับการสมัครงานในบทบาท Management, Design Leadership, Brand & Packaging และ Design Operations

## สิ่งที่เพิ่ม
- เพิ่มหน้า `profile.html` แบบสองภาษา
- เล่าเส้นทางจาก Sculpture และ Product Design ไปสู่ Packaging, Production, Mentoring, Brand Systems และ Business Strategy
- ใช้ตัวเลขจาก Resume ได้แก่ ประสบการณ์ 11+ ปี, 50+ SKU, รายได้หลังเปิดตัว KIOKU +20% และยอดขายหลังปรับโฉม +15%
- เพิ่ม Management Approach ที่อธิบาย Brief, Assignment, Review และ Production
- เพิ่ม Capability Map, Education และ Current Positioning
- ใช้ภาพ Portrait และภาพ Production Collaboration จาก Resume
- เปลี่ยนเมนู Profile บน Home และ Object Study ให้เปิดหน้า Profile ใหม่
- เพิ่มลิงก์ Read the full profile ใน Profile Summary บนหน้า Home

## Responsive
ตรวจโครงสร้างสำหรับ Desktop, Tablet และ Mobile พร้อมรองรับ TH/EN Toggle และ Mobile Menu
