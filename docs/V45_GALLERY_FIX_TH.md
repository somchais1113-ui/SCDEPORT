# V45 — แก้ปัญหา "เส้นบาง ๆ" ในแกลเลอรีหน้าโปรเจกต์ (มือถือ)

## อาการ
บนหน้าจอมือถือ ระหว่างภาพในแกลเลอรีของหน้า `project.html` จะปรากฏเส้นแนวนอน
สีเทาอ่อนพาดเต็มความกว้าง 2 เส้น พร้อมพื้นที่ว่างสีขาวคั่นกลาง ทำให้ดูเหมือน
ภาพโหลดไม่ขึ้นหรือมีเส้นแปลกปลอมแทรกเข้ามา

## สาเหตุที่แท้จริง
ไม่ใช่ปัญหาการโหลดภาพ และไม่ใช่ `<hr>` หรือ divider ใด ๆ แต่เกิดจาก 3 ปัจจัยประกอบกัน

| ลำดับ | จุดที่เกี่ยวข้อง | รายละเอียด |
| --- | --- | --- |
| 1 | `main.css` → `.case-gallery-item--hero / --wide / --half / ...` | บังคับ `aspect-ratio` ตายตัว (มือถือเหลือเพียง `16 / 10` และ `4 / 3`) |
| 2 | `main.css` (v44) → `.case-gallery-trigger img` | ใช้ `object-fit: contain` + `height: 100%` |
| 3 | `main.css` → `.case-gallery-item` | มี `border: 1px solid rgba(27, 28, 26, 0.08)` |

เมื่อสัดส่วนไฟล์ภาพจริงไม่ตรงกับสัดส่วนกล่อง (เช่น ภาพ `1600x900` = 1.78
ถูกวางในกล่อง `4 / 3` = 1.33) `object-fit: contain` จะย่อภาพให้พอดีกล่อง
แล้วเหลือ **แถบขาว (letterbox)** ด้านบนและล่างภายในกล่อง

ผลคือ **ขอบล่างของกล่องบน** และ **ขอบบนของกล่องถัดไป** ลอยอยู่กลางพื้นที่ขาว
จึงถูกมองเห็นเป็นเส้นแปลกปลอม 2 เส้น

> ยืนยันด้วยค่าสี: เส้นในภาพหน้าจอมีค่า RGB = `237, 237, 237`
> ซึ่งตรงกับ `rgba(27, 28, 26, 0.08)` ทับบนพื้นขาวพอดี

## สิ่งที่แก้ไข
เพิ่มไฟล์ `assets/css/v45-gallery-natural-ratio.css` และเรียกใช้ใน `project.html`

- ยกเลิก `aspect-ratio` ที่ breakpoint `max-width: 720px` (ซึ่งเป็นคอลัมน์เดียวอยู่แล้ว)
- เปลี่ยน `.case-gallery-trigger` และ `img` เป็น `height: auto`
- ผลลัพธ์: กล่องสูงเท่าสัดส่วนภาพจริง ไม่มีแถบขาว ไม่มีเส้นลอย เส้นขอบกลับไปแนบภาพ
- เลย์เอาต์เดสก์ท็อป (≥ 721px) ไม่เปลี่ยนแปลง

## ผลการตรวจสอบ
ทดสอบด้วย Chromium headless ที่ viewport 390px และ 430px (DPR 3)

| รายการ | ก่อนแก้ | หลังแก้ |
| --- | --- | --- |
| แถบขาว letterbox แนวตั้ง (px) | สูงสุด 11 | 0 ทุกภาพ |
| แถบขาว pillarbox แนวนอน (px) | สูงสุด 37 | 0 ทุกภาพ |
| เส้นลอยระหว่างภาพ | พบ | ไม่พบ |
| กล่องภาพเดสก์ท็อป 1440px | 1152×648 / 629×472 | เท่าเดิม |

หน้า `home.html` และ `category.html` ตรวจแล้วไม่พบอาการเดียวกัน

## ข้อควรระวังต่อไป
1. **สัดส่วน `layout` ใน `data/projects.js` ควรตรงกับไฟล์ภาพจริง**
   ปัจจุบันมีการกำหนดไม่ตรง เช่น ภาพ `1400x1100` (สัดส่วน 1.27) ใช้ `layout: "wide"`
   ซึ่งออกแบบไว้สำหรับภาพแนวนอนจัด แม้จะไม่ทำให้เกิดเส้นแล้ว
   แต่จังหวะการจัดหน้าบนเดสก์ท็อปจะยังคลาดเคลื่อน
2. ควรคง attribute `width` / `height` ในแท็ก `<img>` ไว้เสมอ เพื่อจองพื้นที่
   ป้องกัน Cumulative Layout Shift ระหว่างโหลด
3. หากต้องการให้เดสก์ท็อปใช้สัดส่วนภาพจริงด้วย ให้เปิดใช้บล็อกที่คอมเมนต์ไว้
   ท้ายไฟล์ `v45-gallery-natural-ratio.css`
