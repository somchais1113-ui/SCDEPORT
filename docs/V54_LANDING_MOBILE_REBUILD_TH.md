# v54 — แก้หน้า Landing บนมือถือ

แก้เฉพาะ `index.html` และเพิ่มไฟล์ `assets/css/v54-landing-mobile.css`

- เปลี่ยน mobile layout ให้เรียงตามเนื้อหาจริง ไม่ใช้แถว `1fr` ที่สร้างช่องว่างขนาดใหญ่
- บังคับให้ภาพ carousel แสดงเสมอบนมือถือ แม้สคริปต์เปิดหน้าโหลดช้าหรือไม่ทำงาน
- แสดงหมวดงานครบทุกหมวดแบบ 2 คอลัมน์ ไม่เลื่อนแนวนอนและไม่ตัดปุ่มสุดท้าย
- ปรับภาพเป็นสัดส่วน 4:3 เต็มความกว้าง พร้อมปุ่มเลื่อนภาพสำหรับการแตะ
- เอาพื้นดำก้อนใหญ่รอบ footer ออก เหลือปุ่ม Enter portfolio ที่ชัดเจน
- ไม่แก้ Home, Project, Category, Craft หรือหน้าอื่น
