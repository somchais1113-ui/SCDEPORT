# ตรวจทาน SCDEPORT — v76

จัดทำวันที่ 7 กันยายน 2026 จาก Source File ที่แนบมา ยังไม่ได้แก้หรือเผยแพร่เว็บที่ใช้งานอยู่บน Vercel

## ผลการตรวจ

เว็บมีภาพผลงานพร้อมใช้งานหลายชุด แต่ชื่อและคำอธิบายบางส่วนยังเป็นข้อความเทมเพลต ทำให้เนื้อหาไม่ตรงกับภาพ จุดที่กระทบความน่าเชื่อถือมากที่สุดจึงเป็นความตรงกันของข้อมูล ไม่ใช่เพียงการเติมภาพให้เต็ม

ฉบับนี้คงโครงสร้างและทิศทางภาพของเว็บเดิมไว้ ปรับเนื้อหาให้แสดงงานออกแบบ การดูแลทีม และความเข้าใจด้านการผลิตได้ชัดขึ้น

|---|---|
| Offset | แผนภาพ 4 ภาพ: ถ่ายทอดหมึก แยกสี ซ้อนทับสี และแปรรูปกล่อง |
| Gravure | แผนภาพ 4 ภาพ: เซลล์ลึก ใบมีดปาดหมึก การพิมพ์ม้วน และลามิเนตตัวอย่าง |

| Screen Printing | ภาพปกและแผนภาพ 4 ภาพ: บล็อกภาพ การปาดหมึก เลือกหมึก และตรวจผิว |

| Home | แผนภาพ 4 จุด: ลำดับงาน ภาระงาน ฟีดแบ็ก และการผลิต |

รวมภาพใหม่ **26 ไฟล์** เป็น SVG ที่สร้างเพื่ออธิบายหลักการ มีคำกำกับอังกฤษในภาพและคำบรรยายไทย–อังกฤษบนเว็บ ไม่ใช่ภาพถ่ายโรงงานหรือหลักฐานผลงานจริง ไม่ได้นำภาพของผู้ผลิตภายนอกมาใช้เป็นผลงานของเจ้าของเว็บ

คงภาพปก Offset, Gravure และ Engraving ที่มีมาในต้นฉบับไว้ โดยไม่ได้ยืนยันแหล่งที่มาหรือความแม่นยำของรายละเอียดเครื่องจักรในภาพเหล่านั้น

นำภาพที่ไม่สัมพันธ์กับผลงานออกจากแกลเลอรีที่แสดงบนเว็บ:

- Packaging: ภาพเทมเพลตท้าย 3 ภาพ
- Campaign: ภาพเทมเพลต 9 ภาพ โดยใช้ภาพงานคาแรกเตอร์ที่มีอยู่เป็นชุดนำเสนอ 2 ภาพ
- Other Creative: ภาพเทมเพลต 10 ภาพ โดยใช้ภาพรถ Stationery Express ที่มีอยู่ 1 ภาพ
- Display: ช่องภาพว่างท้าย Quantum และ KIOKU อย่างละ 2 ภาพ

ไฟล์ภาพเดิมยังอยู่ในโฟลเดอร์ สามารถเรียกกลับมาได้ ขณะนี้แกลเลอรีที่เปิดใช้งานมี **80 ภาพใน 11 รายการ**

## ข้อมูลที่ยังต้องยืนยันจากเจ้าของผลงาน

ตรวจยืนยันไม่ได้จากภาพและ Source File เพียงอย่างเดียว จึงไม่ได้สร้างข้อมูลใหม่แทน:

1. **บทบาทและเครดิตรายโปรเจกต์** — ออกแบบเอง กำกับศิลป์ ดูแลทีม เตรียมไฟล์ หรือประสานงานผลิต รวมถึงผู้ร่วมงานและขอบเขตจริง
2. **ปีผลงาน** — ต้นฉบับระบุ 2026 ทุกรายการ อาจเป็นปีจัดพอร์ต ไม่ใช่ปีผลิต ฉบับนี้คงไว้รอข้อมูลจริง
3. **ผลลัพธ์ +20% / +15% / 200+ SKU** — คงตัวเลขเดิม แต่ปรับคำไม่ให้สื่อว่าเกิดจากดีไซน์เพียงปัจจัยเดียว ควรเพิ่มช่วงเวลา ฐานเปรียบเทียบ และที่มาที่เปิดเผยได้
4. **ที่ตั้ง** — ส่วนใหญ่ระบุ Bangkok แต่ Footer หน้า Profile ระบุ Samut Prakan ควรเลือกให้สอดคล้องกัน ฉบับนี้ไม่เดาสถานที่จริง
5. **ประสบการณ์ 11+ ปี ตำแหน่ง และการศึกษา** — คงจากต้นฉบับ ไม่ได้ยืนยันกับประวัติบุคคลภายนอก
6. **สถานะภาพ** — บางชุดเป็นภาพนำเสนอหรือ mockup เมื่อทำ Case Study ควรระบุว่าภาพใดเป็นแนวคิด ภาพจำลอง หรืองานผลิตจริง
7. **Engraving ที่ต้องการสื่อ** — ฉบับนี้ใช้การสลักผิวด้วยเครื่องมือตามภาพปากกา หากตั้งใจสื่อถึงเลเซอร์หรือการพิมพ์ด้วยแม่พิมพ์แกะลึก ต้องเปลี่ยนทั้งภาพและคำให้ตรงกัน

ข้อเสนอในการพัฒนาต่อ: เลือกงานเด่น 3–5 งานจากภาพรวมมาทำ Case Study ที่มีโจทย์จริง บทบาท ข้อจำกัด การตัดสินใจ และผลลัพธ์ จะช่วยให้ประเมินศักยภาพระดับ Supervisor ได้มากกว่าการเพิ่มจำนวนภาพเพียงอย่างเดียว

## การตรวจสอบและนำไปใช้

- ตรวจ JavaScript syntax, ลิงก์และไฟล์ภายใน HTML/CSS, ข้อมูลโปรเจกต์และกระบวนการ
- ตรวจการสร้างเนื้อหา Craft index, รายละเอียดทั้ง 5 กระบวนการ และกรณีไม่พบข้อมูล รวม 14 กรณีสำหรับสถานะ EN/TH
- เรนเดอร์และตรวจภาพ SVG ที่สร้างขึ้นทั้งชุด
- แก้ขนาด width/height ของข้อมูลแกลเลอรีให้ตรงกับไฟล์จริง และเปลี่ยนเลข cache ของไฟล์ที่แก้
- **ยังไม่ได้ทดสอบในเว็บเบราว์เซอร์จริงหรือบน Vercel** จึงไม่อ้างว่าการจัดหน้าทุกขนาดจอและปฏิสัมพันธ์ผ่านการตรวจแล้ว

แตก ZIP แล้วจะพบ `index.html`, หน้า HTML อื่น ๆ, `assets/` และ `data/` ที่ระดับเดียวกัน ใช้โครงสร้างนี้กับวิธีอัปเดต Vercel เดิม เว็บยังเป็น Static และไม่มี dependency ใหม่ที่ต้องติดตั้งเพื่อใช้งาน

ก่อนเผยแพร่ ให้เปิดหน้าแรก Home หน้าโปรเจกต์ และ Craft ทั้ง 5 กระบวนการ สลับ EN/TH และตรวจบนมือถือ โดยเฉพาะหัวเรื่องที่ยาวขึ้น พร้อมยืนยันข้อมูลตามรายการข้างต้น
