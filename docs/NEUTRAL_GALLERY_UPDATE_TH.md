# Neutral Gallery UI Update

เวอร์ชันนี้ปรับระบบสีให้ทำหน้าที่เป็นกรอบนำเสนอ โดยไม่แข่งขันกับสีของสินค้า โปสเตอร์ และภาพโปรเจกต์

## หลักการสี

- พื้นหลัก: Warm White `#F7F7F4`
- ตัวอักษรและ Footer: Graphite `#1B1C1A`
- พื้นรอง: Soft Neutral `#EEEEEA` และ Warm Stone `#E7E5DF`
- Accent: Grey Green `#85897E` ใช้เฉพาะจุดเล็ก เช่น status dot และ focus state

## จุดที่ปรับ

- ตัด Cobalt Blue, Orange และ Acid Lime ออกจากส่วนติดต่อผู้ใช้
- ปรับ Hero stamp จากวงกลมสีสดเป็นป้ายโปร่งแสงขนาดเล็ก
- ลดการเร่ง Saturation ของภาพเมื่อ Hover เพื่อรักษาสีจริงของผลงาน
- ปรับ Filter, Button และ Navigation ให้เป็นขาว–ดำแบบเรียบ
- เปลี่ยน Approach section เป็น Warm Stone แทนพื้นดำและสี Accent สด
- เปลี่ยน Footer เป็น Graphite และ Next Project เป็น Soft Neutral
- ปรับหน้า Project detail, 404, Favicon, Theme Color และ Preview tool ให้ใช้ระบบเดียวกัน
- คง Layout แบบ Editorial และ Responsive behavior เดิมไว้
