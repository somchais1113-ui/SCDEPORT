# V58 — Design Leadership Narrative

## เป้าหมาย
ปรับเฉพาะเนื้อหาครึ่งล่างของ Main Page ให้สื่อสารความสามารถด้าน Design Management, Team Operations และ Production โดยคงภาษาภาพและโครงสร้างหลักของเว็บไซต์เดิม

## การปรับหลัก
- เปลี่ยน From Thought to Form เป็น Design Leadership 3 แกน: Alignment, Workflow Visibility และ Feedback for Growth
- เพิ่ม Team Operating System แบบ Interactive 5 ขั้นตอน: Brief, Assignment, Design Review, Production, Delivery
- เปลี่ยน Craft & Process ให้เล่าผ่านมุม Creative Direction ที่เข้าใจการผลิต
- ลดบทบาท Object Study ให้เป็น Selected Experimental Case Study
- ปรับ Profile ให้ระบุประสบการณ์ดูแลทีมขนาดเล็ก 2–3 คน และ Positioning สำหรับ Design Manager / Creative Lead / Design Operations
- ปรับ Navigation เป็น Work / Leadership / Production / Profile

## หมายเหตุด้านเนื้อหา
ระบบ Performance ถูกวางกรอบเป็นเครื่องมือสำหรับ Coaching, Workload Balance และการตัดสินใจ ไม่ใช่ระบบจับผิดบุคลากร
