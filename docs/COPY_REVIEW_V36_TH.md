# SCDEPORT v36 — Landing White & Copy Review

การปรับปรุงรอบนี้

- เปลี่ยนพื้นหลัง Landing Page เป็นสีขาวบริสุทธิ์ `#FFFFFF`
- ปรับ `theme-color` และ `site.webmanifest` ให้เป็นสีขาว
- ตรวจความสม่ำเสมอของชื่อโปรเจกต์และตัวพิมพ์ใหญ่–เล็ก
- ปรับข้อความ `Strategy to production` เป็น `From strategy to production`
- แก้คำว่า `retract mechanism` เป็น `retraction mechanism`
- ปรับไวยากรณ์ `independent from` เป็น `independent of`
- ตรวจ JavaScript, CSS, HTML, path รูปภาพ และ duplicate IDs แล้ว
